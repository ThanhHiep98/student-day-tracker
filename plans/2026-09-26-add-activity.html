Plan: Add Activity (write flow)

2026-09-26 · requirement §1.3 · agent: planner → next: implementer

Scope

Turn the disabled + Add Activity button on Home into a working form: name, category (fixed defaults + inline "new category"), start/end time. Submitting writes an Activity to Dexie; Today's Timeline and the Daily summary card update immediately via the existing live queries — no new query plumbing needed. Out of scope: editing/deleting an existing activity (next slice), Insights.

Requirements

Req.BehaviorAcceptance check

(implied) Can't submit nonsense: empty name, or end time at/before start time Inline error text, submit button disabled/no-ops until valid

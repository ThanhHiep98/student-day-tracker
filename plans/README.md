# plans/

Implementation plans produced by the `planner` agent (`.claude/agents/planner.md`), one
self-contained HTML file per feature slice — open directly in a browser, no build step. Filename:
`<YYYY-MM-DD>-<slug>.html`. The `tester` agent stamps a `Status: Shipped <date>` line at the top
of a plan once its success criteria are verified.

See [`CLAUDE.md`](../CLAUDE.md) for the full Plan → Implement → Test workflow.
